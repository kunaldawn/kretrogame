# What the player's runtime leaves out that kretro's keeps.
#
# One glob per line, relative to the runtime root. assemble-runtime removes
# every match when it builds the player profile. Everything here is something
# the player provably never runs: it installs nothing, reads no discs through
# an archiver, rips no audio and edits no prefix by script. Anything a game
# might plausibly load stays; a mistake there costs a game, a mistake here
# costs megabytes.

# The authoring tools: they read discs and archives and run installers, and a
# player only ever runs what an author already installed.
